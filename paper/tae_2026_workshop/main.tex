\begin{abstract}
Evaluation-purpose probes can exploit benchmark structure rather than evaluation purpose. We study this failure with an English controlled purpose $\times$ format factorial design. The paper's primary tests are an equal-training-row control, an all-layer decomposition into shared purpose ($A$), format ($B$), and purpose$\times$format interaction ($C$), and a frozen residual-stream counterfactual transport protocol on held-out purpose families. We report the strongest claim supported by these tests; current local results are development diagnostics and are not treated as confirmation-grade evidence.
\end{abstract}
