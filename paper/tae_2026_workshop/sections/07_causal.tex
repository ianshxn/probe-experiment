After geometry, we froze a layer-selection rule before inspecting intervention outcomes. Eligible layers require held-out pooled purpose AUC $\geq 0.80$ and exclude the first/last block; for the 8B development artifact, layer 5 is the lowest-interaction eligible layer and layer 16 the highest. Training purpose families estimate raw-space $\hat A$, $\hat B$, and $\hat C$. At an eligible layer, purpose transport uses $-2p(\hat A+f\hat C)$ and format transport uses $-2f(\hat B+p\hat C)$; main-effect-only ablations remove $C$. The same rule is being applied independently to the exact cached 3.3-70B geometry, with selection frozen by job `51494932`.

The frozen protocol requires direct candidate-logit baseline validation before steering, randomized candidate mappings, raw-space strength calibration, zero-strength/sign controls, and fixed random directions. After access approval, the independent one-H100 Llama-3.1-8B baseline retry (`51515708`) completed on all 288 items. The frozen purpose endpoint was near chance (accuracy/AUC $0.4757/0.4747$), while the format endpoint reached $0.5694/0.5988$; because the predeclared minimum-accuracy threshold is $0.55$, transport job `51515710` correctly refused causal steering before modifying any held-out activation. This is an endpoint-validation failure, not a null intervention result. We froze a separate internal-mediation fallback before inference, using the same layers and raw-space directions but downstream projection readouts rather than candidate logits; job `51520918` is pending. The exact cached 3.3-70B baseline and transport path (`51495134` / `51495235`) remains independently dependency-gated.
