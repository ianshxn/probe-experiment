\section{Causal Counterfactual Transport}
After geometry, we froze a layer-selection rule before inspecting intervention outcomes. Eligible layers require held-out pooled purpose AUC $\geq 0.80$ and exclude the first/last block; for the 8B development artifact, layer 5 is the lowest-interaction eligible layer and layer 16 the highest. Training purpose families estimate raw-space $\hat A$, $\hat B$, and $\hat C$. At an eligible layer, purpose transport uses $-2p(\hat A+f\hat C)$ and format transport uses $-2f(\hat B+p\hat C)$; main-effect-only ablations remove $C$. The same rule is being applied independently to the exact cached 3.3-70B geometry, with selection frozen by job `51494932`.

The frozen protocol requires direct candidate-logit baseline validation before steering, randomized candidate mappings, raw-space strength calibration, zero-strength/sign controls, and fixed random directions. The independent one-H100 Llama-3.1-8B baseline job (`51503230`) failed before model loading because the approved Hugging Face credential returned HTTP 403 for the gated exact revision; an earlier independent retry (`51488273`) failed for the same access reason. No 8B baseline or steering outcome exists; this is a technical access failure, not evidence for or against the causal hypothesis. The 8B transport job (`51503331`) was dependency-gated and did not run. A separate exact cached 3.3-70B baseline and transport path (`51495134` / `51495235`) is independently dependency-gated and has not produced an inspected outcome.

No causal transport figure or outcome table is reported in this version: the 8B endpoint failed before baseline, while the exact cached 3.3-70B protocol is still dependency-gated. Reporting a transport effect before those gates pass would convert an engineering artifact into a causal claim.
