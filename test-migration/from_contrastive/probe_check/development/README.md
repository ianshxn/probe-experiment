# Probe development analyses

Nothing in this directory is confirmatory evidence. These analyses used the
development corpus or already-spent controls to diagnose the stimulus design
and select recipes before each prospective run.

- [baseline/](baseline/) contains the original extraction notebook, frame
  variants, and early 1B/8B results.
- [layer_selection/](layer_selection/) contains the cross-stratum,
  layer-position, and explicit-contract analyses that selected mean layer 6.
- [cue_constraints/](cue_constraints/) contains cue-balanced augmentation,
  penalty development, and the analysis that selected the final constrained
  recipe.

Read the numbered confirmations for binding results. Historical result text may
describe a script by its former flat location; the file itself is now grouped
under the appropriate development directory.
